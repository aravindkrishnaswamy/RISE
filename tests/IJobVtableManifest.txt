# IJob vtable manifest -- FULL NORMALIZED SIGNATURE per virtual, in
# declaration order (the vtable ABI).  Format v2 (2026-08-20).  Each
# non-comment line below is one entire pure-virtual declaration
# collapsed to a single canonical line by NormalizeDeclSignature in
# tests/SourceHygieneTest.cpp -- NOT just the method name.  The name is
# derivable by parsing the identifier before the first '(', so nothing
# here restates it separately.
#
# WHY FULL SIGNATURES, NOT JUST NAMES.  A name-only manifest cannot see
# a trailing DEFAULTED parameter appended to an EXISTING virtual -- that
# is still a vtable/ABI break: changing a pure virtual's signature on a
# shipped abstract interface changes the vtable layout and breaks
# out-of-tree overriders (docs/VITREOUS_ENAMEL.md:894-899,
# docs/gui/RENDER_COORDINATOR.md:1237-1239).  It is not hypothetical: the
# doc-88 S7 review (2026-08-20) found exactly this -- two IJob virtuals
# had grown a trailing defaulted parameter while the name-only v1
# manifest stayed green throughout.  This file exists so that can never
# happen silently again.
#
# CONSUMED BY: SourceHygieneTest (tests/SourceHygieneTest.cpp, the "IJob
# vtable append-only + full-signature manifest" block).  The header's
# virtuals must match this sequence EXACTLY, signature and all.
#
# A LEGAL CHANGE is a tail append: a brand-new virtual goes at the END of
# IJob's class body, and its normalized signature is added as ONE new
# line at the END of this file, in the SAME commit -- a conscious,
# reviewable ABI decision.  A mid-list insert / reorder / rename /
# removal / in-place signature change (including a merely-appended
# default parameter) fails the suite: it moves or changes a vtable slot
# and breaks out-of-tree binaries (see the abi-preserving-api-evolution
# skill).
#
# REGEN PROCEDURE.  After a reviewed, intentional signature migration or
# a legal tail append, regenerate this file mechanically instead of
# hand-editing it -- generator and checker must never drift apart:
#
#     RISE_REGEN_IJOB_VTABLE_MANIFEST=1 ./bin/tests/SourceHygieneTest
#
