Legacy deprecation Phase 2 slice C: look review

The last migration slice: the quickstart sample (shapes) and the three Android catalogue scenes that were held back from slices A–B2, migrated by the same tools (tools/migrate_scenes_legacy_rasterizer.py, tools/migrate_scenes_legacy_families.py), plus four scenes whose only frozen rasterizer was a commented-out chunk, found by the tools' new --audit (no live scene outside scenes/Tests/Legacy/ and visiblehuman has a frozen ACTIVE rasterizer). All renders at reduced resolution with the shipped sample counts and Sobol' value salts (3 for the four migrated scenes at long side 160; 1 at long side 96 for the comment-only scenes); thumbnails are salt 1, the PRE-denoise image composited over black (RGB × coverage alpha), linear Rec.709 luminance of that image, mean over the salts (± is the salt-to-salt sd). The "Final, denoised" column is the shipped OIDN output (denoising stays on as authored).

Quickstart sample: scenes/Tests/Geometry/shapes.RISEscene

Mean 0.130026 → 0.129872 (-0.12%). printf "render\nquit\n" | ./bin/rise scenes/Tests/Geometry/shapes.RISEscene renders 800×800 in 0.63–0.66 s (legacy 0.60–0.64 s) and no longer logs the frozen-rasterizer warning. The quickstart command is unchanged; README / AGENTS / CLAUDE now say what it writes and that rendered/ must exist.

Flags and decisions for the owner

  • Retune applied (precedent): kaleidoscope_atrium lights x0.951, because both components of its +5.2% are legacy biases (missing indirect light, invented material energy). Revert by restoring powers 80 / 132 / 95 / 35 if the brighter indirect look is preferred.
  • Proposed, not applied: tidepools x1.013 (-1.3% is below any earlier retune).
  • Authored-intent losses: none found. kaleidoscope_atrium's design premise was "recursive reflections"; PT renders those (glass, GGX metals) without Whitted's depth cap, and its max_recursion 6 is gone (PT bounds paths itself). The tidepools shell keeps a view-dependent pearl colour (thin film) rather than the iridescent painter's two-colour blend.
  • Coordinator's multi-rasterizer report: spectral_skinmodel and rwsss_bdpt do not have an MLT ACTIVE rasterizer; their MLT chunks were inside /* */ (as was bdpt_torus_chain_atrium's). The blocks are removed anyway. The only live scene with two rasterizer chunks is FeatureBased/VCM/vcm_sdf_luminaire_jellyfish (PT then VCM; VCM, the last, is active), which documents the double declaration on purpose (it reproduces an agent session) and is left as is.
