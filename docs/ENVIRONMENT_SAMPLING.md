# Environment proposal coordinates and power

The RGB EnvironmentSampler table uses equal-solid-angle cells: azimuth `phi=2*pi*u` and `z=1-2*v`, each with area `4*pi/(width*height)`. Build evaluates the actual source painter's `GetRadianceColor` at cell centres through the light-probe UV mapping, includes source scale, and uses its nonnegative max-channel value as an importance proxy. This is not CIE luminance. The painter record carries the corresponding world ray. Configured map orientation is an orthogonal world-to-map orientation; sampling transforms its map direction back with the transpose, and PDF queries transform world directions to map space.

The normalized midpoint cell PMF is mixed with a fixed 5% uniform-solid-angle component before constructing the marginal/conditional CDFs. Every cell has positive proposal mass even if its midpoint is dark. If all midpoint probes are zero at positive source scale, the proposal is entirely uniform; the table remains valid because missed probes cannot certify blackness. An explicit zero source scale disables the RGB table. Sampling selects a row and conditional column from this single integrated table, then samples uniformly inside that entire solid-angle cell. There is no extra mixture draw or mixture-branch input remapping. The queried density is `cellPMF / cellSolidAngle`. The table has no clipped probe-disk cells and no probe-UV Jacobian. The old square UV table assigned full square-cell mass even when a cell crossed the probe disk, folding samples with theta greater than pi back onto the sphere. Its pole limiting PDF also used an inconsistent pi factor. Both were sampling-domain errors; returning a different PDF alone would not repair that distribution.

Azimuth zero is canonical at exact poles, and ordinary cell boundaries use the query's canonical cell. Density at these measure-zero seams/poles is defined by that query convention; Sample returns the same density for its final world direction. Independent constant/nonconstant integrals and cell-frequency tests validate the sampling distribution separately from sample/query equality.

`TotalLuminance()` retains its existing name but now returns the midpoint approximation of the angular integral of the scaled max-channel RGB proxy. A constant proxy C gives `4*pi*C`, independently of table resolution. The former value was a resolution-dependent sum of UV texel weights, so this correction changes environment-versus-finite root importance proportions; sample and MIS queries continue to use the same actual class PMF. The uniform support component never changes this raw midpoint estimate; in particular, zero estimated power does not mean zero source emission. Weights are exponent-normalized before CDF sums/divisions. An unrepresentable scalar angular integral or nonfinite RGB source is explicitly rejected; a failed build has no valid stale CDF.

Legacy root selection compares `angularIntegral*pi*sceneRadius^2` with the finite alias-table total, forming the ratio from log masses without overflowing products or sums. When both classes are present, the environment share is `.025 + .95*estimatedEnvironmentRatio`: a 5% uniform mixture over the two root classes. An estimated zero environment ratio therefore retains a 2.5% root share. This is explicit proposal policy, not a physical-power clamp or fabricated power. An environment-only scene keeps probability one even if all probes miss its emission; absent/zero-scale/radius-zero environment classes keep probability zero. A finite class is present when its alias table is valid, as in root sampling itself. Nonfinite upstream finite-light power and invalid environment power/radius are refused explicitly. The spectral-domain root policy remains separate and unchanged.

These are continuous proposal support contracts. They do not certify arbitrary source features against the renderer's finite 32-bit Sobol grid: sufficiently narrow patches, tiny within-cell intervals, and legacy root conditional remapping can still have no representable draw. The 5% support mixture keeps ordinary table cells and class intervals away from zero; it is not a source-coverage certificate or a guarantee for arbitrary scientific transport.

The actual painter-backed RadianceMap now shares a robust light-probe mapping with proposal construction. `-Z` maps to disk centre `(0.5,0.5)`, and exact `+Z` maps to disk edge `(1,0.5)` at canonical azimuth zero. Azimuth and polar angle are computed separately with exponent normalization, hypot and atan2; there is no denominator epsilon, subnormal reciprocal, or acos domain failure. Both RGB and NM source queries use this helper. The spectral-domain environment proposal remains uniform in world solid angle, and its power estimate still calls the actual map NM evaluator; this repair does not add a spectral directional CDF or a source-coverage certificate.

`EnvironmentSamplerDomainTest` covers resolution-independent constant integrals, independent PDF/source integrals, affine and highly skewed sources, cap cells with dark midpoint rows/columns and positive uniform support, cell draw frequencies against independent mixture weights, rotations, first/last Sobol inputs and poles, mixed subnormal RGB/NM source directions, extreme root power ratios and nonfinite-power refusals and a non-HyLIoS RGB point-plus-environment NEE oracle. A cap at `z>.99` lies beyond every resolution-64 midpoint (`max z=.984375`); both an all-missed source and the cap plus an observed lower-hemisphere patch are tested alone and with a point light against the analytic direct-only NEE cap integral. This path has no BSDF continuation to recover missing proposal support. It uses tiny fixtures without a rasterizer or image render.

The Hosek sky's legacy adapter keeps its historical equirectangular UV weight approximation; this repair does not change that angular weighting. Its lifetime is corrected: the map owns the adapter's initial reference, and the adapter owns an immutable value copy of the sky model. A caller-retained painter therefore supports RGB/NM queries after the parent sky map is destroyed, without a dangling model pointer or an extra retained reference. A dedicated test checks reference counts and both emission paths across destruction.
