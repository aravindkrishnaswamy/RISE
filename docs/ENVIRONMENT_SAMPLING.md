# Environment proposal coordinates and power

The RGB EnvironmentSampler table uses equal-solid-angle cells: azimuth `phi=2*pi*u` and `z=1-2*v`, each with area `4*pi/(width*height)`. Build evaluates the actual source painter's `GetRadianceColor` at cell centres through the light-probe UV mapping, includes source scale, and uses its nonnegative max-channel value as an importance proxy. This is not CIE luminance. The painter record carries the corresponding world ray. Configured map orientation is an orthogonal world-to-map orientation; sampling transforms its map direction back with the transpose, and PDF queries transform world directions to map space.

Sampling selects a row and conditional column, then samples uniformly inside that entire solid-angle cell. The queried density is `cellPMF / cellSolidAngle`. The table has no clipped probe-disk cells and no probe-UV Jacobian. The old square UV table assigned full square-cell mass even when a cell crossed the probe disk, folding samples with theta greater than pi back onto the sphere. Its pole limiting PDF also used an inconsistent pi factor. Both were sampling-domain errors; returning a different PDF alone would not repair that distribution.

Azimuth zero is canonical at exact poles, and ordinary cell boundaries use the query's canonical cell. Density at these measure-zero seams/poles is defined by that query convention; Sample returns the same density for its final world direction. Independent constant/nonconstant integrals and cell-frequency tests validate the sampling distribution separately from sample/query equality.

`TotalLuminance()` retains its existing name but now returns the midpoint approximation of the angular integral of the scaled max-channel RGB proxy. A constant proxy C gives `4*pi*C`, independently of table resolution. The former value was a resolution-dependent sum of UV texel weights, so this correction changes environment-versus-finite root importance proportions; sample and MIS queries continue to use the same actual class PMF. Weights are exponent-normalized before CDF sums/divisions. An unrepresentable scalar angular integral or nonfinite RGB source is explicitly rejected; a failed build has no valid stale CDF.

Legacy root selection compares `angularIntegral*pi*sceneRadius^2` with the finite alias-table total. It now forms that ratio from log masses without overflowing the products or sum. Absent/zero-estimate/radius-zero environment classes keep probability zero, and environment-only scenes keep one. Mixed legacy ratios outside `[2^-31,1-2^-31]` are refused with a diagnostic, because each live class must retain at least two cells of the renderer's 32-bit Sobol input grid. No arbitrary power clamp or fallback floor silently changes the legacy proposal. Nonfinite upstream finite-light power is also refused explicitly. The legacy remapped conditional draw and other finite-grid limitations are not certified for raw scientific transport by this repair; production spectral-domain mixed roots have their separate independent conditional draw and support policy.

The actual painter-backed RadianceMap now shares a robust light-probe mapping with proposal construction. `-Z` maps to disk centre `(0.5,0.5)`, and exact `+Z` maps to disk edge `(1,0.5)` at canonical azimuth zero. Azimuth and polar angle are computed separately with exponent normalization, hypot and atan2; there is no denominator epsilon, subnormal reciprocal, or acos domain failure. Both RGB and NM source queries use this helper. The spectral-domain environment proposal remains uniform in world solid angle, and its power estimate still calls the actual map NM evaluator; this repair does not add a spectral directional CDF or a source-coverage certificate.

`EnvironmentSamplerDomainTest` covers resolution-independent constant integrals, independent PDF/source integrals, affine and highly skewed sources, exact cap cells with zero rows/columns, cell draw frequencies against analytic source weights, rotations, first/last Sobol inputs and poles, mixed subnormal RGB/NM source directions, extreme root power ratios/refusals and a non-HyLIoS RGB point-plus-environment NEE oracle. It uses tiny fixtures without a rasterizer or image render.

The Hosek sky's legacy adapter keeps its historical equirectangular UV weight approximation; this repair does not change that angular weighting. Its lifetime is corrected: the map owns the adapter's initial reference, and the adapter owns an immutable value copy of the sky model. A caller-retained painter therefore supports RGB/NM queries after the parent sky map is destroyed, without a dangling model pointer or an extra retained reference. A dedicated test checks reference counts and both emission paths across destruction.
